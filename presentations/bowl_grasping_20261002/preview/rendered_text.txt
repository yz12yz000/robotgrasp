What changed from the initial grasping pipeline
Three ROS packages retained; perception, geometry and execution extended.


 Area                       Earlier capability                      Current implementation

 Perception                 Single-target output                    Multiple instances + depth diagnostics


 Rim geometry               One preferred contact                   Up to 8 supported candidates per bowl


 Motion                     Approach / descend / lift               Six-stage grasp, transfer and placement


 Task execution             Reuse one target snapshot               One bowl per round; then observe again


 Operation                  Separate manual processes               Mode isolation, logs and process supervision


  Contribution: an integrated, testable manipulation pipeline with explicit failure handling.
