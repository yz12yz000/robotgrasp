# hand_control ROS 2 Humble package

This package is a ROS 2 Humble port of the ROS 1 `handControl` serial gripper package.

## Main differences from the ROS 1 version

- ROS 1 `handControl` was renamed to ROS 2 package `hand_control`, because ROS 2 package names should be lowercase.
- `hand_control_cmd.msg` was renamed to `HandControlCmd.msg`; the topic name remains `handControlCmd`.
- `roscpp` was replaced with `rclcpp`.
- The ROS 1 `serial` package dependency was removed. The serial port is now handled with Linux `termios`, so no extra serial library is needed.
- The global `SerialClass *serClass` callback pattern was removed. The driver is now a normal `rclcpp::Node` class.
- Packet creation/parsing was separated from serial I/O.
- The protocol header byte follows the original `protocol.h`: `FF FF FC 00`, not the standard Dynamixel `FF FF FD 00`.
- The default control-table addresses are copied from the original `protocol.h`: ID=6, Enable=39, Control=41, LED=40, HomingOffset=20, PresentPosition=56, PresentCurrent=58.
- For `GPC`, `GPP`, and `GHO`, the default behavior matches the original ROS 1 code: read address 0 with length 62, then extract values from the returned register block.
- The old infinite `talker` loop was changed to publish once by default. You can still pass repeat count and rate.

## Build

```bash
mkdir -p ~/hand_control_ros2_ws/src
cd ~/hand_control_ros2_ws/src
# copy the hand_control folder here
cd ~/hand_control_ros2_ws
source /opt/ros/humble/setup.bash
colcon build --symlink-install --packages-select hand_control
source install/setup.bash
```

## Serial permission

```bash
ls /dev/ttyUSB*
sudo usermod -aG dialout $USER
# log out and log in again, or reboot
```

Temporary test permission:

```bash
sudo chmod 666 /dev/ttyUSB0
```

## Run driver

```bash
source /opt/ros/humble/setup.bash
source ~/handControl2_ws/install/setup.bash
ros2 launch hand_control hand_control.launch.py port_name:=/dev/serial/by-id/usb-FTDI_FT232R_USB_UART_00000000-if00-port0 baudrate:=115200
```

If the port opens correctly, you should see:

```text
Serial Port was opened: /dev/ttyUSB0, baudrate=115200
the present id is XX
```

## Send commands

```bash
ros2 run hand_control talker Open 1
ros2 run hand_control talker Close 1
ros2 run hand_control talker Enable 1
ros2 run hand_control talker Disable 1
ros2 run hand_control talker GID 1
ros2 run hand_control talker GPC 1
ros2 run hand_control talker GPP 1
ros2 run hand_control talker GHO 1
ros2 run hand_control talker SID 2
ros2 run hand_control talker SHO 100
ros2 run hand_control talker LED 1
ros2 run hand_control talker LED 0
```

The same command can also be sent directly with `ros2 topic pub`:

```bash
ros2 topic pub --once /handControlCmd hand_control/msg/HandControlCmd "{msgtype: 'Open', value: 1}"
```

## Important hardware note

Before writing ID (`SID`) or homing offset (`SHO`), disable the gripper first:

```bash
ros2 run hand_control talker Disable 1
ros2 run hand_control talker SID 2
```

## Control table parameters

The default addresses in `config/hand_control.yaml` now come from the original ROS 1 `protocol.h`. In most cases you should not need to change them.

Important defaults:

```yaml
id_address: 6
enable_address: 39
control_address: 41
led_address: 40
homing_offset_address: 20
present_position_address: 56
present_current_address: 58
use_state_block_read: true
state_block_start_address: 0
state_block_read_length: 62
```
